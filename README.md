# Exploratory Data Analysis (EDA) Project

## Internship
**Thiranex — Task 3**

## Project Overview
This project performs Exploratory Data Analysis (EDA) on a sample sales dataset to understand sales patterns, product performance, and city-wise trends.

## Objectives
- Understand the structure and quality of the dataset.
- Identify missing values and duplicate records.
- Calculate statistical summaries.
- Analyze sales by product and city.
- Explore correlations between numerical variables.
- Present insights using visualizations.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Analysis Performed
1. Dataset inspection and data quality checks
2. Statistical analysis
3. Total sales by product
4. Total sales by city
5. Correlation matrix visualization
6. Product-wise sales distribution
7. Key findings and final EDA report

## Files Included
- `Task3_Exploratory_Data_Analysis.ipynb` — Notebook containing code, analysis, and visualizations.
- `EDA_Final_Report.txt` — Text report summarizing the analysis.

## Dataset Note
The dataset is sample data created for educational purposes. The findings do not represent actual business performance.

## Conclusion
This project provided practical experience in data exploration, statistical analysis, data visualization, and reporting using Python.
